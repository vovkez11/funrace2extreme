# RaceFun 2: Neon Rush

A compact HTML5 arcade racer that runs directly in the browser with no external assets or dependencies.

## What changed

- Three-lane traffic patterns with guaranteed escape routes
- Frame-rate independent movement, spawning, scoring, and difficulty
- Near-miss combo system and Neon Fever mode
- Nitro meter with keyboard and mobile boost controls
- Coins plus Shield, Nitro, and Time Warp pickups
- Random run challenges with score bonuses
- Particles, screen shake, animated road lights, and synthesized sound effects
- Responsive mobile/desktop UI and improved pause behavior
- Persistent local high score

## Controls

- **Left / Right:** Arrow keys or A / D
- **Nitro:** Hold Space
- **Pause:** Escape or Pause button
- **Mobile:** On-screen left, boost, and right buttons

Open `index.html` in a modern browser to play.
